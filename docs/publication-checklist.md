# Publication review
Review before any commit or push to the public repository, and again before publication.

- [ ] No private home addresses, accommodation addresses, gate codes, access instructions, or private meeting points.
- [ ] No guest names tied to travel, guest flights, guest contacts, or guest lists.
- [ ] No credentials, tokens, private keys, environment files, local machine paths, or private drafts in tracked files or Git history.
- [ ] Host flights and contact details remain placeholders unless explicitly approved for public display.
- [ ] Partiful link is approved for public linking and reveals only intended information.
- [ ] Linked documents contain no private information, including comments, revision history, embedded metadata, and sharing permissions.
- [ ] Photographs and logos are licensed or host-owned; personal image location metadata has been removed.
- [ ] Yellowstone Club information does not disclose private access arrangements or imply confirmed guest access.
- [ ] Times, venues, reservations, pricing, transfers, and participation requirements are verified or visibly unconfirmed.
- [ ] All links work; pending resources have no fake links.
- [ ] noindex, nofollow appears in built HTML. It discourages indexing and is not privacy protection.
- [ ] Source and built output have both been reviewed; ignored local files are not accidentally staged.
- [ ] Mobile, keyboard, navigation, accordion, reduced motion, and build checks pass.
- [ ] Publication approval applies to this exact reviewed revision.
- [ ] Any DNS modification has separate explicit approval.

Record the reviewed revision and approval in the private approval conversation, not by copying private correspondence into this repository.
